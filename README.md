# 🚀 Advertisement ROI Prediction Dashboard (Power BI)

An interactive Power BI dashboard that analyzes digital advertising campaign performance across platforms like Facebook, Google, TikTok, and YouTube.  
The project focuses on evaluating ROI, conversions, and audience behavior to support data-driven marketing decisions.

---

## 📊 Project Overview

This dashboard helps businesses understand:
- Which advertising platforms perform best
- How budget impacts ROI
- Which audience segments convert more
- Which ad types generate higher engagement

It transforms raw advertising data into meaningful business insights.

---

## 💡 Key Insights

- TikTok delivers the highest ROI among platforms  
- Video ads perform better than image ads in engagement and conversions  
- Age group 25–34 shows the highest conversion rate  
- Higher budget does not always guarantee higher ROI  
- Funnel analysis shows drop-off from impressions → clicks → conversions  

---

## 📈 Dashboard Features

- KPI Cards (Revenue, Cost, ROI, CTR, Conversions)  
- Platform performance analysis  
- Ad type comparison  
- Audience segmentation insights  
- Budget vs ROI relationship  
- Conversion funnel visualization  
- Profit classification (Profitable / Loss / Break-even)
